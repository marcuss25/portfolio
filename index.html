BridgeMEI | Gestão Financeira

Aplicação web desenvolvida em equipe para auxiliar microempreendedores individuais na organização e gestão do negócio. O projeto inclui funcionalidades como controle de estoque, registro de vendas, e indicadores de faturamento em um painel administrativo.

Sistema de Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em C++, com funcionalidades de cadastro, busca, listagem, empréstimo e devolução de livros. Utiliza programação orientada a objetos e persistência de dados em arquivos para armazenar os registros.

API de Login

API desenvolvida em C# com ASP.NET Core para gerenciamento de autenticação de usuários. Implementa cadastro e login, utilizando JWT para autenticação por tokens e MySQL para armazenamento de dados. O projeto está disponível como código-fonte, mas a API não está atualmente hospedada ou em funcionamento.
